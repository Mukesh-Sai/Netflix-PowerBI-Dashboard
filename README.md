# Netflix-PowerBI-Dashboard
This Power BI dashboard is designed in a Netflix-inspired theme, creating a visually immersive and familiar experience similar to browsing the real Netflix interface. The dashboard is built using comprehensive Netflix dataset fields, including:

Show ID
Title
Rating
Cast
Directors
Genre
Release Date
Available Regions

The key highlight of the dashboard is its interactive exploration capability. When a user selects any movie or TV show, the dashboard dynamically updates to display the title's complete detailed information—from its cast and creators to its maturity rating, genre classification, and global availability.
With a clean layout, bold visuals, and Netflix-like styling, this dashboard provides:

A cinematic, theme-based browsing experience
One-click insights for any selected show or movie
Easy analysis of genres, ratings, and release trends
A modern, engaging interface that blends aesthetics with functionality
